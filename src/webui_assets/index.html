高级参数说明 通常保持默认

这些参数是在“模型时间轴”之后做的有限修正。先听成片，再只调整最相关的一两项。

边界与时间轴

boundary_limit · 自动边界最大调整
限制起点或尾点吸附的最大距离。调大可能修复偏移，但更容易吸附到相邻声音。
gap_max · 句内断档阈值
同一句歌词内部间隔超过此值时，认为出现错锚并尝试重排。长间奏歌曲可适当调大。
min_line_dur · 最短行时长
防止字幕一闪而过。调大能提高可读性，但可能造成相邻句重叠。
char_rate_min · 每字最短时长
按字数给短句设置下限，主要防止密集副歌闪现；快速 Rap 不宜设得过大。
char_dur_max · 单字时长上限
限制单个字挂在屏幕上的最长时间。设为 0 表示不限，适合保留拖音。
tail_gain · 拖音延长上限
人声仍在唱时，允许把最后一个字延长的最大秒数。现场混响重时应谨慎调大。

人声引导

vocal_thr · 活跃人声阈值
判断人声是否存在的能量门槛。调低会保留更多弱声，也可能把观众声当成人声。
rel_drop_db · 弱能量剔除
相对主唱能量低于此值的短段会被忽略；设为 0 可关闭。
start_snap · 起点吸附
把歌词起点靠近检测到的人声开始处，适合抢跑明显的现场录音。
tail_clamp / clamp_tails_per_line · 尾部收回
人声结束后仍在显示的字幕会收回，避免尾部挂屏。
tail_extend · 拖音补偿
人声尾音仍在持续时延长最后一个字；关闭后更保守。

置信度与异常修正

conf_high / conf_low · 高低置信阈值
划分可靠、可疑的歌词行。它们影响是否允许自动修正，不是准确率。
ev_prob / ev_dur · 证据词门槛
判定某行是否有足够可靠的词级声学证据，避免用退化闪点定位。
relocate_lowconf · 低置信行搬移
把明显错位的低置信行放入附近未占用的人声区间。重复副歌时建议谨慎。
zeroconf_collapse / zeroconf_p · 零置信压缩
压缩几乎没有声学证据的退化时间轴，避免整句错误铺开。

交叉检查与规则开关

tx_crosscheck · 转写交叉验证
用独立转写检查人声区间是否像歌词。喊叫、和声较多时可能误删，默认策略通常已关闭。
tx_min_match / tx_prune_min / tx_max_seg / tx_cap_frac
控制交叉验证的匹配门槛、最短剪除长度、最长可剪段和总剪除比例。只有启用上项时才生效。
reflow_gapped / fix_over_long · 断档与超长修正
分别处理句内大断档和整句过长。属于较激进的修正，建议先用自动均衡模式。
drop_beyond_vocals · 删除人声区外歌词
移除落在最后一段人声之后的行。现场版本少唱尾段时有用，但需要确认确实没唱。
enforce_timing · 最短时长与不重叠
最后的结构安全检查，保证时间轴可渲染；通过不代表字幕一定唱准。

4人工微调对齐 —

给某一行填「偏移 ms」即可整体平移该行（正数延后、负数提前）； 点 ▶ 可把播放器跳到该行起点试听。改完点「应用并重新渲染」—— 只重跑字幕与编码，不重新对齐，通常几秒完成。

展开歌词可逐字/词填写偏移。偏移相对于当前选中版本，整行与字词偏移会相加。播放器显示已渲染版本，提交后才会更新高亮；时间顺序冲突会被自动整理，需复核结果。

#歌词起点（秒）终点（秒） 偏移 ms

起点、终点可独立输入秒数；修改后句内字词按原有相对位置等比伸缩。若同时填整行偏移，会在新起止时间上叠加偏移。播放器与定位依据仍是已生成版本，提交后更新。

人工锚点 · 重新对齐后续

先用偏移调整并试听确认一句歌词，再选为锚点。将应用该句及之前的待提交偏移，锁定它们，从锚点句末重新分析其余音频。后续待提交偏移会由新对齐替代；生成独立版本，可回退。此操作需要模型推理和视频编码。

插入新的歌词

自动定位会锁定插入点前一句，重新对齐新增歌词及后续内容；手动定位直接使用填写的起止秒数，并在区间内均分字词。两种方式都会生成可回退的新版本。
